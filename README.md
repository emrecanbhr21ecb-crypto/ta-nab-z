# TaşNabız

Bazalt taşının gündüz ısısı ile toprağın serinliği arasındaki farktan elektrik üreten, pilsiz ve kablosuz iklim sensörünün kaydırmalı 3B tanıtım sitesi (Tech4Climate Ideathon 2026, Diyarbakır).

Tek dosya: `index.html` (Three.js r128, cdnjs üzerinden). Derleme adımı yok.

## Yerelde çalıştır

```bash
git clone https://github.com/emrecanbhr21ecb-crypto/ta-nab-z.git
cd ta-nab-z
python3 -m http.server 8000
# tarayıcıda: http://localhost:8000
```
